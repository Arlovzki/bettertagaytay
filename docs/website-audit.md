# Better Tagaytay website audit

Better Tagaytay is a community portal for finding city services, government information, and public documents. The review covered the current React/Vite checkout and representative desktop and mobile journeys. Official source links were checked on 5 November 2026.

## Official website comparison

The live pages were fetched directly because indexed versions of the disclosure page omitted newer third-quarter links.

- The [Transparency Seal page](https://www.tagaytay.gov.ph/transparencyseal.html) links to four annual documents under 2026 and ten third-quarter reports. Added those verified links to the portal's full-disclosure page and the budget report link to its budget page. The report periods follow the source labels; the financial contents of those PDFs were not independently audited.
- The [downloads page](https://www.tagaytay.gov.ph/downloads.html) links to building, fencing, and completion forms with 2026 filenames, plus three permit application checklists. Replaced the portal's generic directory destinations with direct verified PDF links and included the checklists and printing instruction.
- Checked 49 distinct official PDF destinations. Forty-eight responded successfully, including a successful retry of the zoning map. The downloads page's `pdf/investment code.pdf` returned 404; the navigation's `pdf/investmentcode.pdf` works and is the link used in the portal.
- The [officials page](https://www.tagaytay.gov.ph/localofficials.html) still lists the same mayor, vice mayor, and council names used here. It provides no term label. Removed the unsupported 2022–2025 term claim from the officials directory and council heading, and added the source and check date. This is a comparison with the published page, not independent verification of officeholders.
- The homepage contains a velodrome feature and an announcement explicitly about May 2025. An announcement's continued presence does not make it a new 2026 announcement.
- Official pages disagree on the City Hall phone: the homepage shows `(046) 888-9500`, while some inner-page footers show `(046) 413-1220`. Both already appear in portal content. No phone number was changed solely because one page repeated it.

## Validation and release status

- TypeScript and production build passed; the final initial bundle is below Vite's 500 kB warning threshold.
- ESLint passed without warnings.
- Five focused Node tests passed, including mobile link preservation and counter request/failure behavior.
- Live counter requests verified separate sessions, concurrent duplicate suppression, rejected writes from other origins, CORS reads, and cleanup of synthetic visits.
- Browser checks covered search, navigation, document switching, translations, contact scrolling, and the counter's actual total. The homepage had no horizontal overflow at 320, 375, 768, or 1440 pixels. The mobile forms page retained all 22 PDF links. No real application, payment, message, or phone call was submitted.
- No Git commit or push was made. The counter backend and frontend are deployed. See the [6 November production release record](production-release-2026-11-06.md).
